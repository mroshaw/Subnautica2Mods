# Subnautica 2 Mods

This repository contains all of my Subnautica 2 mods.

## Beginners Guide Mods

Source code for the example mods referenced in the [Beginners Guide to Modding Subnautica 2](https://subnautica2modding.github.io/beginners-guide/):

- BeginnersGuideLuaCheatMod - an example Lua mod that gives the player unlimited oxygen, food, and water.
- BeginnersGuideCppCheatMod - an example C++ mod that gives the player unlimited oxygen, food, and water.

## Subnautica 2 Mods

### Lua Mods

- TadPoleSpeedMod - simple mod that allows you to apply a multiplier to the max speed of the Tadpole.
